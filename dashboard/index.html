How the implied value is built

No name is ever special-cased. One function scores every row:

implied = TVL × category multiple × growth × maturity × breadth

  • Category multiple. The median market-cap-to-TVL ratio of the live protocols in the same category that already trade, when at least 3 of them carry both figures; otherwise the whole market's median. Clamped to 0.05–1.50. The table below lists every multiple the board used.
  • Growth. The protocol's seven-day TVL change, clamped to −60%…+120%, times 0.6: 1 + growth × 0.6. Missing growth counts as 0%.
  • Maturity. 0.6 + min(age, 1095 days) / 1095 × 0.4. A protocol that has run longer with no token scores higher; unknown age counts as 365 days.
  • Breadth. 1 + 0.02 per extra chain, up to 5 extra chains.
  • The board. All 40 watchlist protocols, plus the pre-token protocols below the $50M floor that pass the same visible filters (no wrapped, staked or bridged product, no versioned name, no exchange product), best implied value first.
  • A limit the snapshot sets. It carries no parent-protocol field, so a child product below the floor can slip past the visible filters. “Records no token” means the record carries none — never that the protocol has none.
